# 🤖 Copiloto com Fluxo de Conversa Personalizado – Microsoft Copilot Studio

Este repositório faz parte do desafio proposto na plataforma, com o objetivo de criar um **Copiloto com Fluxo de Conversa Personalizado** usando o **Microsoft Copilot Studio**.

---

## ✅ O que aprendi

Durante a prática, explorei as principais funcionalidades da ferramenta e aprendi a:

- Criar **tópicos personalizados** para estruturar fluxos de conversa de forma lógica;
- Utilizar **entidades pré-definidas** (como datas e números) e **entidades personalizadas** para capturar informações específicas;
- Definir e aplicar **variáveis globais e locais**, entendendo sua função no armazenamento de dados durante o fluxo;
- Aplicar **fórmulas e condições** para personalizar a interação com o usuário;
- Inserir **respostas generativas** e conectar com **Knowledge Sources**, ampliando a capacidade do chatbot de responder perguntas fora do fluxo padrão;
- Testar e publicar o Copiloto, garantindo que ele funcione de forma fluida e inteligente.

---

## 🛠️ Ferramentas utilizadas

- [Microsoft Copilot Studio](https://learn.microsoft.com/pt-br/microsoft-copilot-studio/)
- GitHub

---

## 🚀 Resultado

Ao final do desafio, criei um Copiloto funcional, com fluxo estruturado, respostas personalizadas e lógica adaptativa. Essa experiência reforçou a importância da automação inteligente no atendimento ao usuário e me mostrou o potencial do Copilot Studio para criar experiências realmente eficientes e humanizadas.
